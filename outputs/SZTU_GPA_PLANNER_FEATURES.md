# SZTU GPA Planner 功能区说明

> 文档用途：说明各功能区解决什么问题、用户如何使用，以及不同模块之间的数据如何流转。  
> 当前阶段：MVP 产品功能基线。

## 1. 产品入口与整体流程

SZTU GPA Planner 面向希望了解当前绩点、规划目标 GPA、模拟未来成绩，以及准备留学申请的深圳技术大学学生。

推荐使用流程：

```text
导入成绩
  ↓
检查和确认课程记录
  ↓
查看当前 GPA 与学分情况
  ↓
设置目标 GPA
  ↓
模拟未来学期与单科成绩
  ↓
持续更新实际成绩
```

用户不需要先注册账号。MVP 默认把数据保存在当前浏览器中，并支持导出备份。

## 2. 总览 / 仪表盘

总览页负责回答三个问题：

1. 我现在的 GPA 是多少？
2. 我的成绩数据是否完整、可信？
3. 我距离目标 GPA 还有多远？

主要展示：

- 当前 GPA，例如 `3.02 / 4.50`。
- 已获得学分。
- GPA 计算学分。
- 平均学分绩。
- 已录入课程和考试记录数量。
- F、P/NP、补考、重修记录数量。
- 各学期 GPA 变化趋势。
- 当前目标 GPA 及所需未来平均 GPA。
- 成绩截图导入入口。

所有结果都应允许展开查看计算依据，包括 GPA 分子、分母和被排除的课程。

## 3. 成绩截图导入

用户可以上传一张或多张教务系统成绩截图，程序识别其中的课程数据。

主要步骤：

1. 电脑端拖入或点击选择截图，手机端从相册/文件中选择；无需安装插件。
2. 自动识别课程名称、课程编号、学分、成绩、等级、绩点和考试性质。
3. 按图片内容删除重复截图，合并多张截图并删除重叠区域产生的重复课程行，同时显示清理数量。
4. 标记低置信度、成绩映射冲突、疑似补考或重修的记录。
5. 用户在表格中检查和修改，可逐条确认或“一键全部通过审核”；缺失、非法或成绩映射冲突的记录保留为未通过状态。
6. 确认后导入“我的课程”。

识别状态：

- 绿色：识别结果与深圳技术大学规则一致。
- 黄色：识别置信度较低，需要用户确认。
- 红色：分数、等级、绩点或学分存在明显冲突。
- 紫色：疑似补考、重修或同一课程的多次考试记录。

系统不能因为课程名称相同就直接删除记录。原始 F 和补考成绩可能同时参与 GPA，因此必须分别保留。

截图默认在本地处理；识别完成后不长期保存原始图片。

## 4. 我的课程 / 成绩管理

该功能区保存用户的完整课程和考试记录，是其他计算模块的数据来源。

主要功能：

- 按学期查看课程。
- 搜索课程名称或课程编号。
- 手动新增、编辑和删除课程记录。
- 查看成绩、等级、绩点、学分和考试性质。
- 查看课程是否计入 GPA。
- 查看课程是否获得学分。
- 展开同一课程的正常考试、补考、缓考和重修记录。
- 标记 P/NP 或“通过/不通过”课程。
- 导入、导出 JSON 数据备份。

课程详情需要区分：

```text
课程
  ├─ 正常考试记录
  ├─ 补考记录
  ├─ 重修记录
  └─ 课程认定或替代关系
```

任何修改都应实时更新总览、目标规划和学期模拟结果。

## 5. GPA 目标规划

该功能区回答：

> 为了把累计 GPA 提升到目标值，未来课程平均需要达到多少绩点？

用户输入：

- 目标累计 GPA。
- 预计剩余 GPA 学分。
- 必要时输入当前 GPA 和当前 GPA 学分。

系统输出：

- 所需未来平均 GPA。
- 目标是否可以实现。
- 对应的大致成绩等级。
- 保守、计划和冲刺三种情景。
- 如果目标不可达，显示在 4.5 满绩点下可达到的理论上限。

示例：

```text
当前质量分：392
当前 GPA 学分：130
目标 GPA：3.30
未来 GPA 学分：60

未来平均 GPA 需要约 3.92
```

目标结果必须使用未四舍五入的原始质量分计算；只有当前 GPA 数字时，应标注为估算。

## 6. 学期模拟

用户可以建立一个未来学期，设置每门课程的目标等级，实时观察学期 GPA 和累计 GPA 的变化。

主要功能：

- 添加未来课程。
- 设置课程学分。
- 选择目标成绩或等级。
- 实时计算本学期 GPA。
- 显示累计 GPA 从当前值到预计值的变化。
- 对比保守、计划和冲刺方案。
- 复制一个方案继续调整。
- 将实际成绩确认后转入“我的课程”。

典型交互：

```text
市场研究：A → B+
    ↓
本学期 GPA 自动变化
    ↓
预计累计 GPA 自动变化
```

模拟数据与正式成绩数据要有明显区别，避免用户把规划成绩误认为已取得成绩。

## 7. 单科成绩计算

该功能区用于反推一门课程剩余考核需要多少分。

用户可以录入：

- 平时成绩及权重。
- 作业、小测、项目、期中、期末等考核项。
- 已知成绩。
- 目标总评成绩或目标等级。

系统输出：

- 当前已经获得的加权分数。
- 剩余考核需要的平均成绩。
- 某一未知考核项至少需要多少分。
- 目标是否已经达成。
- 目标是否超过 100 分、因此不可实现。
- 不同目标等级之间的差距。

示例：

```text
平时 20%：88
项目 20%：92
期中 20%：84
期末 40%：未知
目标总评：85

期末至少需要：80.5
```

考核权重合计不是 100% 时，系统不能直接给出最终结果，必须要求用户检查。

## 8. 历史记录

历史记录用于保存用户过去做过的规划和模拟，避免每次重新输入。

可保存：

- GPA 目标方案。
- 学期模拟方案。
- 单科成绩反推方案。
- 每次成绩导入记录。
- 用户确认和修改过的 OCR 识别结果。

用户可以：

- 查看历史结果。
- 复制旧方案。
- 删除不再需要的方案。
- 恢复到某次导入前的数据状态。
- 导出完整备份。

MVP 可以先保存最近若干条记录，不需要账号和云端同步。

## 9. 设置

设置页负责管理规则显示、数据隐私和本地数据。

主要内容：

- 当前学校规则：深圳技术大学 4.5 绩点制。
- 当前计算策略说明。
- 小数显示位数。
- 是否显示详细计算过程。
- 数据导入和导出。
- 清除本地数据。
- 截图识别隐私说明。
- 待确认规则提示。
- 软件版本和规则版本。

正式重修 GPA 规则尚未完全确认时，应在设置页和相关计算结果中持续显示提示，不能通过默认选项隐藏。

## 10. 帮助与规则说明

帮助区用通俗语言解释：

- GPA 是如何计算的。
- GPA 学分和已获得学分有什么区别。
- 为什么 F 会拉低 GPA。
- 为什么 P/NP 不进入 GPA。
- 为什么补考不能简单覆盖原始 F。
- 哪些结果来自官方规则。
- 哪些规则来自成绩单实证。
- 哪些规则仍需学校确认。

同时声明：

> 本工具用于学习规划和估算，不是深圳技术大学官方教务系统，也不能替代正式成绩单、GPA 证明或排名证明。

## 11. MVP 功能范围

第一版优先完成：

- 我的课程。
- GPA 汇总。
- 目标 GPA 反推。
- 学期模拟。
- 单科成绩反推。
- 成绩截图上传、识别结果校对流程。
- 本地保存和 JSON 备份。
- 计算规则说明。

第一版可以暂缓：

- 教务系统账号自动登录。
- 云端账号和跨设备同步。
- 留学 GPA 转换。
- 培养方案毕业审核。
- 正式成绩单证明生成。
