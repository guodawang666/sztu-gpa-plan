# SZTU GPA Planner 最终交付说明

## 已交付功能

- 成绩总览：累计 GPA、质量分、GPA 学分、已获得学分、所修总学分与考试记录状态。
- 成绩导入：电脑拖放、点击多选、手机相册/文件选择，以及 OCR 文本粘贴。
- 重复保护：识别前按图片真实内容删除重复截图；识别后删除完全相同的课程行，并显示删除数量。
- 人工审核：逐条核对或“一键全部通过审核”；字段缺失、占位课程名、分数等级冲突等记录不会被批量通过。
- 成绩档案：手动新增、删除、JSON 导入和导出；补考与原始成绩分别保存。
- 规划工具：目标 GPA 反推、学期模拟、单科剩余考核成绩反推。
- SZTU 规则：4.5 绩点映射、F 计入 GPA 分母、P/NP 不计入 GPA、正常 F 与补考成绩分别计算。

## 设备与隐私

- 现代电脑和手机浏览器均可使用，不需要安装插件。
- OCR 在浏览器本地运行，应用不收集教务系统帐号和密码，成绩截图不经过本项目后端。
- 首次 OCR 会下载中英文识别模型，之后由浏览器缓存。
- 当前成绩档案保存在本机浏览器；换设备可使用 JSON 备份迁移，暂不自动同步。
- 支持 PNG、JPG/JPEG、WEBP、BMP 和静态 GIF；HEIC 需先转为 JPG 或 PNG。

## 启动方式

```bash
npm install
npm run dev
```

电脑打开 `http://localhost:5173`。需要让同一 Wi-Fi 下的手机访问时运行 `npm run dev:network`，再打开终端显示的局域网地址。

## 验收结果

- 自动化测试：后端 16 项、前端 19 项，全部通过。
- 类型检查：前后端全部通过。
- 生产构建：前后端全部通过。
- 接口冒烟：健康检查、F 加补考双记录、单科反推均通过。
- 真实成绩样例：53 条记录，GPA 学分 130，质量分 392，累计 GPA 3.02，与教务系统一致。
- 重复场景：同内容不同文件名的两张截图只识别一次；合法的原 F 与补考记录不会被当作重复项删除。

## 仍需保留的规则提示

“正式重修”后的累计 GPA 口径尚缺少完整官方原文，因此产品只提示复核，不擅自覆盖历史成绩。普通补考是否全校统一封顶 64 分也仍应以当期学校文件为准。
